# YouTube Brand Deals — GTM Analytics

An end-to-end **go-to-market analytics** project on a YouTube **Brand Deals**–style
business: from raw campaign data to SQL analysis, an interactive dashboard, and a
stakeholder insight narrative that drives a spend-reallocation recommendation.

> **Data disclaimer:** This repo uses a **synthetic, seeded dataset** generated by
> [`data/generate_data.py`](data/generate_data.py). It contains **no real creators,
> brands, or proprietary YouTube data** — it exists so the whole pipeline is
> reproducible. To run on real data, replace the CSVs in `data/` with exports from
> the YouTube Data / Analytics API (or a public dataset) using the same columns.

## What this demonstrates

- **SQL** — star-schema joins + aggregation over three tables (see [`analysis/queries.sql`](analysis/queries.sql))
- **Python data pipeline** — reproducible generation → load → analyze → publish
- **Dashboard design** — a self-contained, accessible HTML dashboard (light/dark, hover tooltips)
- **Insight storytelling** — turning metrics into a narrative that influences a decision ([`insights/insights.md`](insights/insights.md))
- **Metrics that matter for Brand Deals** — ROAS by category & format, seasonality, at-risk spend, top creators

## Headline result

| Metric | Value |
|---|---|
| Media spend | $6.7M (520 campaigns, 60 creators) |
| Attributed revenue | $18.7M |
| Blended ROAS | **2.8x** |
| At-risk spend (campaigns < 1.0x) | **35.8%** |
| Top vertical | Finance — **4.89x** |
| Below break-even | Food — **0.88x** |

**The takeaway:** don't spend more — **reallocate ~$1M** from below-break-even Food
and low-ROI dedicated-video placements into Finance/Tech and cost-efficient Shorts
(~$1M incremental attributed revenue). Full reasoning in
[`insights/insights.md`](insights/insights.md).

## Run it

```bash
python data/generate_data.py      # writes the synthetic CSVs
python analysis/analysis.py       # runs SQL, prints KPIs, builds the dashboard
open dashboard/dashboard.html     # interactive dashboard (no build step, no dependencies)
```

No third-party packages required — standard library only (`sqlite3`, `csv`, `json`).

## Project structure

```
│   ├── brand_deals.csv        # fact: campaigns (generated)

│   ├── dashboard_template.py  # self-contained HTML/SVG renderer

│   └── dashboard.html         # the interactive dashboard (auto-written)
└── insights/
    └── insights.md            # stakeholder insight narrative
```

## How to point it at real data

Swap the three CSVs in `data/` for real exports with matching columns:
`creators(creator_id, creator_name, category, subscribers, country)`,
`brand_deals(deal_id, creator_id, brand, category, format, campaign_month, deal_value_usd)`,
`deal_performance(deal_id, views, likes, comments, avg_view_pct, conversions, revenue_usd, roi)`.
Then re-run `analysis/analysis.py`.
